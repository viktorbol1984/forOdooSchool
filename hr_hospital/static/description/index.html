HR Hospital

Hospital workflow management for Odoo 19

Overview

HR Hospital is a custom module that helps manage doctors, patients, visits, diseases, and diagnoses in a single workflow.

Main Features

  • Doctors and specialities management
  • Doctor schedules and visit availability checks
  • Patient cards and patient-doctor assignment history
  • Visits with domain and validation rules
  • Medical diagnoses and approval metadata
  • Diseases catalog with hierarchy and affected regions
  • Operational wizards and reporting tools

Business Rules

  • Doctor rating must be between 0.00 and 5.00
  • Doctor cannot be archived if active visits exist
  • Duplicate same-day visit for same doctor and patient is forbidden
  • Visit creation requires prior patient-doctor assignment
  • Visit with diagnoses cannot be deleted

Wizards

  • Mass doctor reassignment
  • Disease report wizard
  • Diagnosis report wizard
  • Reschedule visit wizard
  • Doctor schedule wizard
  • Patient card export wizard

Data & Translations

The module includes disease master data and supports translated values for translatable fields via i18n/*.po.

Tests

Automated tests are included for doctors, visits, and diseases models.

Cash Flow

Cashbox and cash flow management for Odoo 19

Overview

Cash Flow helps manage cashboxes, transactions, transfers, and DDS classification.

Main Features

  • Cashboxes with assigned cashiers and cities
  • Actual and planned cash flow transactions
  • DDS categories and articles
  • Cashbox transfers with posting logic
  • Forecast wizard (payment calendar)
  • Printable reports

Business Rules

  • Planned transactions must have a future date
  • Transfer posting creates income/expense transactions
  • Cashiers are restricted to their own cashboxes

Wizards

  • Cash flow forecast wizard

Reports

  • Cashbox balances
  • DDS article turnover

Data & Translations

The module includes demo data and supports translations via i18n/*.po.

Tests

Minimal tests are included for main models.
